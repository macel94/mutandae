Connect what
you own.

Explore the multi-cloud simulator safely (Azure/Entra, AWS IAM, GCP IAM), or open a short-lived session against an Azure / Entra tenant you control. Real-tenant credentials never enter Redis, snapshots, events, logs, or HTML.

Security warning. Only use a temporary client secret for a tenant you own. Mutandae holds it in process memory for at most ten minutes and clears it when the session ends. After trying the demo, invalidate this client secret in Entra ID and remove its consent if you no longer need it.

Live demo · create a real identity

Create a zero-permission identity in a real tenant

The server holds least-privilege credentials for the demo tenants below. Creating an identity there is safe and costs nothing: the result has no permissions — no AWS policy, no GCP role, no Azure API permission or admin consent — so it cannot do anything until you (outside the demo) grant it access. Each visitor may create a few; the demo auto-reclaims the oldest at its quota and throttles requests per client.
